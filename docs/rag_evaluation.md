## 1. Базовая конфигурация системы
Базовые параметры архитектуры и пайплайна:
*   **LLM (Генератор):** `gpt-4o-mini` (temperature: 0.3)
*   **Embedding модель:** `multilingual-e5-base` (размерность: **768**)
*   **Chunking (Разбиение):** `MarkdownNodeParser + SentenceSplitter с настройкой через paragraph_separator \n\n` (размер чанка: **512 токенов**, перекрытие: **64 токена**)
*   **Векторный поиск:** `Qdrant` / Косинусное сходство (Cosine Similarity)
*   **Retrieval параметры:** **top-K = 10**
*   **Ре-ранкер (Re-ranker):** `bge-reranker-v2-m3` (оставляет **top-3** чанка для контекста LLM)

---

## 2. Golden Dataset (Тестовый датасет)
Отрежиссированный набор данных для валидации изменений:
*   **Объем:** **79 пар вопросов и идеальных ответов (Q/A)**.
*   **Способ генерации:** Синтетическая генерация с помощью `Ragas` (инструмент `TestsetGenerator`) на основе корпуса документов.
*   **Валидация:** Проведена **100% ручная вычитка**. Исключены дубли, двусмысленные формулировки и вопросы, на которые нет ответа в базе знаний.

## 8. Известные проблемы и план улучшений
*   [ ] **Time-aware Retrieval:** Добавить кастомное затухание весов (score decay) для старых документов или жесткую фильтрацию по метаданным даты.
*   [ ] **Парсинг таблиц:** Перевести обработку PDF-документов со сложной структурой на `Unstructured` или `LlamaParse` с извлечением таблиц в формат JSON/HTML.
*   [ ] **Гибридный поиск (Hybrid Search):** Интегрировать `BM25` в связке с векторным поиском (Reciprocal Rank Fusion) для точного матчинга по специфичным терминам и артикулам.
*   [ ] **Query Rewriting:** Добавить шаг предобработки запроса (LLM-линтер) для раскрытия аббревиатур перед поиском.
